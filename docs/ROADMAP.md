# Engineering Roadmap

## Phase 1: MVP Launch (Current Release)
- [x] Complete architecture documentation and specifications.
- [x] Python FastAPI backend with deterministic calculation engine, models, schemas, seed data, and unit tests.
- [x] Native Android Java application (MVVM, Room, Retrofit, Material 3, ViewBinding).
- [x] Offline-first Room database with seed catalog (Vi, Jio, Airtel, BSNL plans and real payment offers).
- [x] Google ML Kit OCR screenshot importer and structured term extractor.
- [x] Best Deal recommendation engine with dual metrics (guaranteed vs potential savings).
- [x] Cashback & savings tracker with status lifecycle.
- [x] Android APK build and unit test verification.

## Phase 2: Enhanced Intelligence & Integrations
- [ ] Direct BBPS (Bharat Bill Payment System) bill fetch integration for postpaid users.
- [ ] Push notifications for imminent offer expiry and plan renewal warnings.
- [ ] Cloud synchronization of savings history across multiple user devices with end-to-end encryption.
- [ ] Circle-specific roaming plan alert enhancements.
